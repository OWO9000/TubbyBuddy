TubbyBuddy for Windows
======================

1. Run TubbyBuddy-win32-x64\TubbyBuddy.exe
   (or right-click Install-TubbyBuddy.ps1 -> Run with PowerShell to install
   into %LOCALAPPDATA%\TubbyBuddy with shortcuts).

2. Sign in with Google (it opens your browser) or look around with the
   demo account, then tell Tubby which apps and sites to guard.

3. The app lives in the system tray. Closing the window keeps it running;
   quit from the tray menu.

The block screen can always be closed: x or Escape pauses the guard for
10 minutes, Ctrl+Alt+Shift+P pauses it from anywhere, Ctrl+Alt+Shift+Q quits.
Safe preview: TubbyBuddy.exe --safe-mode (guard off).

For exact website rules, load the extension/ folder in chrome://extensions
(Developer mode).
